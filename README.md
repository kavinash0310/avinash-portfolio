## Run locally

Requirements: Node.js and npm.

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

The contact form uses Resend. Set `RESEND_API_KEY` in an untracked `.env.local` file for local email delivery. Never commit API keys.

## Deploy

Connect this repository to Vercel and deploy the `main` branch. Configure `RESEND_API_KEY` in the project’s environment settings if you want the contact form enabled.
